# 🐍 Snekk

A classic Snake game built with **Rust** using the **Macroquad** game library.

This is my very first project in Rust, developed as a learning exercise to explore the language's syntax, ownership model, enums, structs, and module system.

## 🎮 Controls

| Key                                 | Action                                     |
| ----------------------------------- | ------------------------------------------ |
| **Arrow Keys** (`↑`, `↓`, `←`, `→`) | Control the snake direction                |
| **Space**                           | Restart the game (on Game Over or Victory) |
| **Esc**                             | Exit the game                              |

## 🚀 How to Run

Ensure you have [Rust and Cargo](https://www.rust-lang.org/tools/install) installed on your machine.

1. Clone the repository:
   `git clone https://github.com/your-username/snekk.git`
   `cd snekk`
2. Run the game (using `--release` is recommended for better performance):
   `cargo run --release`

## 🛠️ Tech Stack

- **[Rust](https://www.rust-lang.org/)** - A multi-paradigm, general-purpose programming language designed for performance and safety.
- **[Macroquad](https://macroquad.rs/)** - A simple, cross-platform game library for Rust.
